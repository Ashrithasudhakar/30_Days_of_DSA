# 30 Days Of DSA
A personal learning journey to improve my problem-solving skills, strengthen Data Structures and Algorithms (DSA), and prepare for coding interviews.

# About This Challenge
I have studied programming concepts, but I want to become better at applying them to new problems independently. Through this 30-day challenge, I will practice C++, learn DSA step by step, solve coding problems, and document my progress.

# Language: C++
# Duration: 30 days
# Focus: Problem-solving, DSA, coding interviews

# Daily Practice Method
For every problem, I will try to:
Understand the problem statement.
Work through an example manually.
Write the logic before coding.
Implement and test my solution.
Review mistakes and retry without looking at the solution.
